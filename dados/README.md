# Dados meteorológicos

Esta pasta contém o arquivo de entrada utilizado pelo código do projeto:

`dados_A433_H_2008-04-27_2026-09-12.csv`

Os dados correspondem à estação automática **A433 – Brumado**, do Instituto Nacional de Meteorologia (INMET).

O arquivo contém registros referentes a um período maior que o utilizado no TCC. Para a análise de séries temporais, foram considerados os dados de **2010 a 2024**.

As principais variáveis meteorológicas utilizadas no estudo são:

- temperatura máxima diária do ar;
- radiação solar máxima diária.

Essas variáveis também são utilizadas como entradas para o cálculo diário da capacidade de condução de corrente do condutor de referência.
